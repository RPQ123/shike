# 食刻 · 校园食堂方案设计

校园食堂错峰就餐与窗口分配仿真软件的设计与实现。

网页版与Windows 2.5.0版共用计算代码，支持三维就餐回放、排程、班级放行表和记录导出。

本次研究先比较不实行错峰、仅按年级错峰、年级与班级结合错峰，再比较相邻班组出发间隔。保存660次计算记录，并用另一组随机条件复核所选方案。默认1610人为示例人数，窗口、座位和用时均可调整；各校填写本校条件后重新比较。

- [打开GitHub Pages](https://rpq123.github.io/shike/)
- [备用网站](https://shike-campus-canteen.xyichenlix.chatgpt.site/)
- [报告、软件、源码与研究数据](https://rpq123.github.io/shike/data/)

下载仓库后直接打开index.html可以离线运行。Windows软件完整解压后打开“启动软件.cmd”，无需安装Python。三维场景包括排队、取餐后端盘步行、等座和入座，画面抽样显示，计算记录覆盖全部学生。

本次示例选择70秒。最终复核的平均排队分别为15.34、5.05、0.54分钟；平均完整用时较仅年级错峰增加3.53分钟。排队与完整用时分别记录，不将减少排队写成整次就餐更快。70秒是当前参数和候选范围下的结果。

报告最后一部分为“总结、应用和推广”，说明学校使用方法、放行表实施及记录反馈。下载页提供空白就餐记录表与匿名反馈表；减少烦躁感属于拟检验的应用效果。原有800次与150次研究保留原始参数和来源，与本次研究分别保存。

网页使用JavaScript，Python工具用于生成并核对33组放行表。程序、检索、绘图和文字整理使用AI辅助。build-info.js记录26个程序文件校验值；模型计算数据标注为合成数据。
