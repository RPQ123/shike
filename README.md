# 食刻 · 校园食堂方案设计

校园食堂错峰就餐与窗口分配仿真软件的设计与实现。

网页版与 Windows 2.4 版共用计算代码，支持三维回放、方案比较、班级放行表、逐人记录导出和研究笔记。

本次加入取餐后的端盘步行、满座等候、座位预留和入座动作。点击行走中的学生可以查看路线，在“设置方案”中可调整端盘步行速度。

- [打开 GitHub Pages](https://rpq123.github.io/shike/)
- [备用网站](https://shike-campus-canteen.xyichenlix.chatgpt.site/)
- [研究数据](https://rpq123.github.io/shike/data/)

下载仓库后直接打开 `index.html` 也可以离线运行，无需安装依赖。

默认人数取自对应入学年度的公开招生计划，总计 1610 人。窗口、座位、速度及通道尺寸为实验设置，三维场景按代表人物展示，统计使用全体学生。新加入的 150 次步行对照与原 800 次方案研究分别保存，文件中记录了各自使用的设置。

`data/` 包含场景文件、实验记录和全部研究数据下载包；`build-info.js` 记录程序文件校验值。模型生成的数据均标注为合成仿真数据。

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保证直接提供静态文件。
